# Research Notebooks

This directory contains the Jupyter notebooks associated with the matched cross-domain evaluation of fixed hold-out and five-fold out-of-fold stacking.

## Notebooks

- `Paper_1_CIFAR10_Matched_Holdout_vs_OOF_FINAL.ipynb` — CIFAR-10 matched-protocol experiment.
- `Paper_1_Combined_Results_and_Statistics.ipynb` — combined results and statistical analyses.
- `Paper_1_Matched_Holdout_vs_OOF_Stacking_CLEANED.ipynb` — CT matched-protocol experiment.
- `Paper_3_Protocol_Sensitivity_Extended_Experiments.ipynb` — extended protocol-sensitivity analyses.

**Important:** Some notebooks require datasets and intermediate prediction files that are not included in this repository. Read the root README and `docs/REPRODUCIBILITY.md` before running them. Inspect notebook paths and training cells before execution.
